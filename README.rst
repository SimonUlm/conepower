This is a fork of pandapower, an easy to use network calculation program aimed to automate the analysis and optimization of power
systems. More information about pandapower can be found on `www.pandapower.org <https://www.pandapower.org/>`_. conepower extends
the functionality of pandapower by implementing Jabr's Relaxation, a convex relaxation technique designed to improve the
performance of the non-convex Optimal Power Flow Problem.

Installation Guide:

1. Clone this git repository: `git clone URL`
2. Create conda environment using Python 3.11 or 3.12: `conda create -n myenv python=3.12`
3. Activate conda environment: `conda activate myenv`
4. Navigate to project folder : `cd conepower`
5. Install: `pip install -e ".[all]"`

That should be it. If problems arise, fell free to contact me.
